# WebDesignExam 2025-2026

Progetto universitario sviluppato per l'esame di **Web Design**, durante il **primo anno al Politecnico** (a.a. 2025-2026).

Si tratta di un sito web statico realizzato con **HTML, CSS e JavaScript**, senza framework né librerie esterne, per mettere in pratica le basi viste durante il corso.

🔗 **Sito online:** [melis.lspoldi.com](https://melis.lspoldi.com/)

## Pagine del sito

- `index.html`: home page
- `shop.html`: negozio
- `blog.html` e `articolo.html`: blog e pagina di un articolo
- `recensioni.html`: recensioni
- `aboutus.html`: chi siamo
- `credits.html`: crediti

## Struttura del progetto

```
├── css/          # fogli di stile
├── js/           # script aggiuntivi
├── data/         # dati usati dal sito
├── resources/    # immagini e altre risorse
├── script.js     # script principale
└── *.html        # pagine del sito
```

## Come usarlo

Basta clonare il repository e aprire `index.html` nel browser:

```bash
git clone https://github.com/luca611/WebDesignExam_2025-2026.git
```
